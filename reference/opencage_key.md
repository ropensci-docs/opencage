# Retrieve Opencage API key

**\[deprecated\]**

Deprecated and will be removed from the package together with
[`opencage_forward()`](https://docs.ropensci.org/opencage/reference/opencage_forward.md)
and
[`opencage_reverse()`](https://docs.ropensci.org/opencage/reference/opencage_reverse.md).

Retrieves the OpenCage API Key from the environment variable
`OPENCAGE_KEY`.

## Usage

``` r
opencage_key(quiet = TRUE)
```

## Arguments

- quiet:

  Logical vector of length one indicating whether the key is returned
  quietly or whether a message is printed.

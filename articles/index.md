# Articles

### All vignettes

- [Customise your
  query](https://docs.ropensci.org/opencage/articles/customise_query.md):

  “The OpenCage API supports about a dozen parameters to customise a
  query and here we will explain how to use them.”

- [Introduction to
  opencage](https://docs.ropensci.org/opencage/articles/opencage.md):

  “Get started with the opencage R package to geocode with the OpenCage
  API, either from place name to longitude and latitude (forward
  geocoding) or from longitude and latitude to the name and address of a
  location (reverse geocoding).”

- [Output
  options](https://docs.ropensci.org/opencage/articles/output_options.md):

  “[`oc_forward()`](https://docs.ropensci.org/opencage/reference/oc_forward.md)/[`oc_reverse()`](https://docs.ropensci.org/opencage/reference/oc_reverse.md)
  return lists of various type, namely data frames, JSON, GeoJSON or
  URLs, depending on the `return` value you specify. The possible
  `return` values are `df_list`, `json_list`, `geojson_list` and
  `url_only`.”
